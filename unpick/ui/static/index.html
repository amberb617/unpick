Offline AI add-on scanner

Check an AI add-on before you install it.

Skills, rules files, MCP servers and plugins can carry instructions you never see. unpick reads them the way your AI does, on this computer.

  • Shows the hidden text a Markdown viewer leaves out
  • Finds setup steps and commands that download and run code
  • Reads files and never runs them. Nothing is sent anywhere unless you ask.
